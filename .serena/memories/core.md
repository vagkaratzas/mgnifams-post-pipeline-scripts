# Core

- Repository contains post-processing scripts for MGnifams pipeline outputs; entrypoints live in `bin/`, `paper/scripts/`, the pipelines' `bin/` and `playground/bin/` and are standalone argparse scripts.
- `README.md` documents root-level scripts with usage blocks; add new script notes near the top when introducing or materially changing a script.
- Pipeline-specific annotation workflow lives under `pipelines/annotation_percentages/`; read `mem:tech_stack` for dependencies and `mem:task_completion` for checks.
