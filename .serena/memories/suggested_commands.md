# Suggested Commands

- Run focused tests with `python -m pytest tests/test_<script>.py -q`.
- Run a script's CLI help with `python bin/<script>.py --help`.
- Use `rg --files` and scoped `rg -n <pattern> <path>` for repository search; generated assets under `assets/mgnifams_v2_results/multiqc/` can be very noisy.
